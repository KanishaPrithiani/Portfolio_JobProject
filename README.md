# Kanisha — Portfolio Website

A premium, single-page React portfolio built with clean custom components, custom interactive animations, and responsive layouts.

## Features

- **Interactive Hero & Intro Morph**: Smooth 3D rotateY flip animation between the black & white bust and the red silhouette.
- **Custom Cursor**: Custom pointer dot with a smooth lagging trailing ring.
- **Smooth Scroll**: Customized, silky lerp-based scrolling.
- **Word Tagline Reveal**: Paragraph spans that light up sequentially on scroll.
- **Infinite Marquee**: Edge-fade masked tagline scrolling marquee.
- **Glassmorphism Cards**: Blurred cards resolving to crisp, clean states as they enter the viewport.

## Getting Started

In the project directory, run:

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm start
   ```
   Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

3. Build for production:
   ```bash
   npm run build
   ```

## Folder Structure

```text
src/
├── assets/          # PNG thumbnails & hero assets
├── components/      # Modular React sections (Navbar, Hero, Services, etc.)
├── data/            # Static dataset (projects list, services list, testimonials)
├── hooks/           # useScrollEffects (scroll animations & intersection observers)
├── index.css        # Core design tokens and vanilla CSS styles
├── index.js         # React entry point
└── App.js           # Main layout
```
